# 数据与合规说明｜万物声谱

## 1. 数据类型与用途

| 数据 | 用途 | 当前存储/传输 |
|---|---|---|
| 纸质声卡照片 | 辅助老师录入固定字段 | 保存在当前浏览器；当前不发送给视觉模型 |
| 儿童或环境录音 | 生成可编排声音、作品播放与回溯 | 保存在当前浏览器；不发送给作品理解模型 |
| 声音配方和编排 | 基础编排、作品理解、背景生成 | 本地保存；仅匿名结构摘要可发送给模型 |
| 贡献者称呼、地点、时间 | 儿童理解与来源回溯 | 本地保存，不进入作品理解模型 |
| 模型结果 | 背景层、音乐发现、操作建议 | 与作品一起本地保存，并记录来源类型 |

## 2. 最小化与隐私边界

- 作品理解接口仅接收声音数量、高低、长短、变化、轻响、重复方式、作品时长、疏密、重叠和情绪等匿名结构数据。
- 不向文本模型发送姓名、照片、原始录音、具体地点或可识别儿童身份的信息。
- 数据默认保存在当前设备浏览器，不提供跨设备共享或公开作品社区。
- API Key 只存在服务端环境变量，不写入仓库和客户端代码。
- 用户可在应用中重置演示数据；正式学校部署仍需补充清晰的监护人/学校授权和数据删除制度。

## 3. 未成年人和教育边界

- 产品服务于音乐兴趣启发和创作体验，不进行成绩评定、能力排名、心理判断或学情定论。
- AI 输出只提供儿童可理解的音乐现象和一次可操作尝试，不替代教师教学判断。
- 老师负责纸卡内容和声音来源的必要确认；儿童保留选声、摆放、情绪和是否保留背景的决定。
- 不通过低置信度识别结果替儿童做决定，也不把模型输出描述为唯一正确答案。

## 4. 音频与生成内容安全

- 原始音频不可覆盖，所有处理以参数和作品事件形式保存。
- AI 背景位于独立音轨，可关闭、可拒绝、低增益播放。
- 音乐提示词要求无歌词、无人声、无抢占性主旋律；背景生成失败不影响儿童基础作品。
- 文本模型结果必须通过结构、字段覆盖、时长和教育价值校验，不合格结果自动拒绝并使用本地规则。
- Fun-Music Preview 返回临时音频地址；正式长期归档前必须转存到具备授权和生命周期管理的自有对象存储。

## 5. 接口保护和已知限制

- 演示接口设有单访客限频、实例并发和单实例每日限额。
- 当前限频状态保存在运行实例内，不能视为多实例生产环境的全局配额；正式部署应接入共享存储、监控和告警。
- 外部模型可能出现超时、权限失败或输出不合格；界面会提示真实状态，并提供重试、Plan B 或纯儿童原声路径。

## 6. 数据与素材授权

- 示例音频由项目方提供并确认可公开用于当前演示，具体文件和状态见 `docs/asset-licenses.md`。
- 项目使用的开源依赖及版本记录在 `package-lock.json`；商业模型与接口在 README 和环境变量示例中披露。
