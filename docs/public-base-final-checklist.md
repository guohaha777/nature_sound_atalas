# 万物声谱｜公共基座最终核对表

本表是 00B 建立的最终审计基线。各页面只验收自己涉及的条目；06 全链路完成后再统一复核全部条目。

## 版本规则

- 数据库结构变更：新增 Dexie 版本与迁移，不在组件内临时兼容。
- 六字段听感规则变更：升级 `musicMapping` 并更新固定测试。
- 排谱行为变更：升级 `arranger`；相同输入、seed 和版本必须得到相同事件表。
- 情绪映射变更：升级 `emotionMapping`；情绪只用于整首作品的创作参数。
- 演示资产或默认关系变化：升级 `demoManifest`，同时更新哈希和许可清单。
- AI 输入约束变化：升级 `polishPrompt`；缓存键必须包含输入哈希、prompt 和模型版本。
- 版本常量统一登记在 `src/domain/shared/versions.ts`。
